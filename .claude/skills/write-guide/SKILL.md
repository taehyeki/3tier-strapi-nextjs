연수자용 문서 규칙. 연수자는 일본인이며, 자신이 설계한 3층 인프라 위에 이 흐름을 **참고해서** 적용한다.

## 최우선 목적
- 연수자가 **질문 없이** 읽고 따라 해서 3층 아키텍처의 개발·배포를 이해하는 것. 누가 언제 봐도 재현할 수 있어야 한다.
- 결과만이 아니라 "무엇을 왜 했는지"를 남긴다. 연수자는 이걸 자기 유스케이스로 바꿔 만들어야 한다.
- 톤: "똑같이 따라 하라"가 아니라 **"이런 방식으로 한다, 참고해서 자기 것을 만들어라"**. 라멘 가게는 예시이며 입력 값은 "(예시)"로 표시한다.
  사진 등 소재는 제공하지 않는다 (도식에 쓰는 그림은 예외). 단, 명령과 설정은 그대로 재현 가능하게 적는다.
- 대상 독자는 프론트·백엔드 개념이 처음인 사람. 화면 코드는 디자인(className)을 뺀 요약으로 "받아 온 값이 화면의 어디에 나오나"를 부분 코드 + 부분 스크린샷으로 보여 주고, 실제 파일·화면과 다를 수 있다고 명시한다. map·Promise.all 같은 구현 기법 설명은 최소화.
  핵심 부분(예: 가게 이름, 메뉴 카드)만 부분 스크린샷, 나머지는 표로 정리하고 **전체 화면 1장**으로 보여 준다.
- 각 장 끝에 커밋 단계를 둔다 (장 단위 1커밋, Conventional Commits). 저장소 커밋과 1:1 대응.
- 코드를 싣는 기준: 누가 만들든 필요한 **연결·설정·보안·빌드/배포** 코드는 전부 싣고 설명한다.
  화면 꾸미기(컴포넌트, 스타일)는 연수자마다 다르므로 코드를 싣지 않고 개략과 짚을 점만 쓴다.
  Strapi 는 설정 코드가 적고 대부분 화면 조작이므로 화면 중심으로 쓴다.
- 문서에 싣는 코드는 저장소 파일에서 직접 읽어 넣어 불일치를 막는다.
- 기능은 최소(Read)로, 방식은 베스트 프랙티스(시크릿 분리, 최소 권한, 설정은 환경변수 등)를 철저히.
- 새 개념(데이터 타입, 관계, 시크릿 등)은 **일상적인 비유 + 구체적 예시**로 먼저 설명하고, 판단 기준(질문 형태)을 준다.
- 장 구성: 00 전체 구조(도식) → 01 로컬 환경 → 02 스키마 → 03 데이터·API → 04 화면 → 05 GitHub·CI → 06 배포.

## 쓰고 나서 반드시 검토
- 각 섹션이 그 장의 목표(goal)에 직접 필요한가? 아니면 삭제한다. "알아 두면 좋은" 내부 동작(DB 테이블 구조 등)은 넣지 않는다.
- 같은 내용이 표·그림·본문으로 중복되지 않는가? 가장 잘 전달되는 하나만 남긴다.
- 파일이 생기거나 바뀌는 단계에는 📁 디렉터리 상태가 있는가?
- 문서의 명령·파일 내용이 저장소와 정확히 일치하는가? (실제로 실행해서 확인)

## 언어와 파일
- 먼저 한국어(`docs/ko/*.html`)로 쓴다. 담당자 승인 후에만 일본어(`docs/ja/*.html`)로 번역한다.
  번역은 직역하지 말고 자연스러운 일본어 기술문서 톤(です・ます)으로.
- 각 장은 독립 HTML 파일 하나. 공통 CSS는 `docs/assets/guide.css`. 외부 CDN 없이 오프라인으로 열려야 한다.
- 라이트/다크 모두 읽히게.

## 문체
- 간결하게. 한 단계 = 목표 한 줄 + 명령/조작 + "성공하면 이렇게 보인다"(스크린샷 또는 출력).
- 배경 설명은 접을 수 있는 `<details>` 로 빼서 본문을 짧게 유지한다.
- 기초로 **배포까지 반드시 도달**하게 쓰고, 중급·심화는 각 장 끝 "더 해보기"에 방향만 제시한다 (열린 결말).

## 필수 요소
- 도식: AWS 공식 Architecture Icons 를 인라인 SVG로. 요청 흐름은 번호 붙은 화살표로.
- 스크린샷: `docs/assets/img/`. 계정 ID·이메일·토큰은 가린다.
  같은 성격의 조작(예: 필드 추가 반복)은 **대표 예시 1장**만 싣고, 나머지는 표 + "같은 방법으로 등록"으로 줄인다.
  새로운 개념이 처음 나오는 화면, 오류 화면처럼 배울 거리가 있는 화면만 남긴다. 문서에서 안 쓰는 이미지는 지운다.
- 유료 GitHub 기능이 필요한 단계에는 배지: "필요 플랜: … / 없으면 생략 가능".
- 명령에는 실행 위치(어느 디렉터리)를 적는다.
- 계정 ID, 리전 외 환경값은 `<YOUR_...>` 플레이스홀더로.
