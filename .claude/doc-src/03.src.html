CHAPTER 03 · 백엔드 DB

데이터와 API: 그릇에 담고, 창구로 꺼낸다

02장의 그릇에 데이터를 담고, 화면(Next.js)이 그 데이터를 꺼내 갈 수 있도록 "읽기 전용 출입증(API 토큰)"을 발급합니다. 이 장도 코드는 쓰지 않습니다.

{{MAP:03}}

관리자 화면에서 데이터를 입력·공개하고, API 토큰을 발급해 curl로 메뉴 데이터를 꺼내 본다.

1. 데이터 입력과 공개

왼쪽 메뉴의 Content Manager에서 그릇마다 데이터를 입력합니다. 연결될 쪽을 먼저 만듭니다: Topping·Extra를 만든 뒤 Menu에서 그것들을 고릅니다.

입력하는 곳이 자료의 예시
Shop麺屋ヤマモリ, 한 줄 소개, 주소·영업시간·정기휴일·식권 규칙, 가게 사진
Topping ×4ニンニク・ヤサイ・アブラ・カラメ (양: ナシ / フツウ / マシ / マシマシ)
Extra ×2ライス 100, チャーシュー 200 (사진 포함)
Menu ×2ラーメン, つけ麺 (사이즈별 면 양·가격, 연결할 토핑·추가 메뉴)
Save와 Publish는 다릅니다. Save는 임시 저장이라 밖으로 나가지 않습니다. Publish를 눌러야 API로 나갑니다(= 사이트에 표시). "저장했는데 사이트에 안 나와요"의 원인은 대부분 Publish를 안 한 것입니다.
여기서 입력한 데이터는 이 PC의 DB에만 있습니다. Git에도 들어가지 않고 운영으로 배포되지도 않습니다. 운영에서는 운영 관리자 화면에서 다시 입력합니다(06장).

2. API: 백엔드의 "주문 창구"

Strapi는 입력한 데이터를 자동으로 API(프로그램이 데이터를 받아 가는 창구)로 내줍니다. 주소는 /api/복수형이름입니다. 먼저 그냥 불러 봅니다.

실행 위치: 아무 곳 (Strapi 실행 중)

curl http://localhost:1337/api/menus
{"data":null,"error":{"status":403,"name":"ForbiddenError","message":"Forbidden",...}}

403(권한 없음)이 정상입니다. Strapi의 API는 처음에 모두 잠겨 있습니다. 여는 방법은 두 가지입니다.

방법누가 읽을 수 있나이번 선택
Public 역할에 권한 부여인터넷의 누구나
API 토큰토큰(출입증)을 가진 쪽만✔ Next.js 서버만 가진다
API 토큰은 주방 창구의 출입증입니다. 출입증을 홀 직원(Next.js 서버)만 갖고 있으면, 손님(브라우저)은 창구에 직접 오지 못하고 반드시 홀 직원을 거칩니다.

3. API 토큰 발급

Settings → API Tokens → Create new API Token.

항목값이유
Nameweb (local)누가 쓰는 출입증인지 알 수 있게
Token typeCustom필요한 권한만 고르기 위해
PermissionsMenu·Topping·Extra: find findOne / Shop: find읽기만. 만들기·수정·삭제는 허용하지 않는다

Save를 누르면 토큰이 표시됩니다. 비밀번호와 같으므로 채팅이나 Git에 붙여 넣지 않습니다.

"Read-only"가 아니라 "Custom"을 고르는 이유 생략 가능

Read-only는 회원 정보 등 모든 데이터를 읽을 수 있습니다. Custom으로 화면에 필요한 것만 허용하면, 토큰이 새어도 피해가 메뉴 정보를 읽는 데서 그칩니다(최소 권한).

4. 토큰을 붙여서 다시 요청

실행 위치: 아무 곳 (Strapi 실행 중)

TOKEN=복사한_토큰
curl -H "Authorization: Bearer $TOKEN" "http://localhost:1337/api/menus?populate=*"
{ "data": [ { "name": "ラーメン", "sizes": [ { "label": "small", "price": 800 }, … ], … }, … ] }

403 대신 입력한 메뉴가 JSON으로 돌아옵니다.

보낸 것결과의미
토큰 없음403누구인지 모르므로 거절
틀린 토큰401출입증이 가짜
올바른 토큰200 + 데이터출입증도 진짜, 권한도 있음
올바른 토큰으로 권한 밖(예: /api/users)403출입증은 진짜지만 그 문은 못 연다
?populate=*는 무엇인가요? 생략 가능

Strapi는 기본으로 글자·숫자 필드만 돌려줍니다. 사진·부품·연결(Relation)은 "함께 가져와 달라"고 해야 포함됩니다. populate=*는 "한 단계 아래까지 모두 포함"이라는 뜻입니다.

5. 토큰을 Next.js 쪽에 둔다

지금 curl로 한 일을 04장부터는 Next.js 서버가 합니다. 그래서 토큰은 apps/web의 환경변수 파일에 둡니다.

apps/web/.env.local

진짜 토큰을 넣는다. Git에 올리지 않음

apps/web/.env.example

"STRAPI_URL과 STRAPI_API_TOKEN이 필요하다"만 적은 예시. Git에 올림

실행 위치: 저장소 루트

cp apps/web/.env.example apps/web/.env.local
# apps/web/.env.local 을 열어 STRAPI_API_TOKEN= 뒤에 토큰을 붙여 넣는다
변수 이름 앞에 NEXT_PUBLIC_을 붙이면 안 됩니다. 붙이면 값이 브라우저로 가는 코드에 섞여 누구나 볼 수 있게 됩니다. 또 create-next-app이 만든 apps/web/.gitignore는 .env*를 모두 무시하므로, 끝에 !.env.example을 추가해 예시 파일만 커밋되게 합니다.
