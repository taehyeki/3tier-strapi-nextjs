1. 이번 연수에서 하는 것

여러분은 이미 3층 아키텍처(웹 → 앱 → DB)의 인프라를 설계했습니다. 이번에는 그 위에 올라갈 애플리케이션을 직접 만들고, GitHub를 통해 자동으로 배포하는 흐름을 체험합니다.

예시는 キム系 라멘 가게 「麺屋ヤマモリ」의 메뉴 사이트입니다. 가게 직원이 관리자 화면에서 메뉴와 가격을 입력하면, 손님이 보는 사이트에 그대로 반영됩니다.

이 자료는 정답이 아니라 참고 예시입니다. 코드는 저장소에 모두 있으니, 문서에서는 흐름과 핵심만 읽고 여러분이 만들고 싶은 사이트(주제·데이터·화면)로 바꿔서 만들어 보세요. 라멘 가게의 데이터와 사진은 제공하지 않습니다. 생략 가능 표시가 붙은 부분은 몰라도 따라올 수 있는 보충 설명입니다.

2. 3층 구조를 가게에 비유하면

웹 서비스는 크게 세 부분으로 나뉩니다. 라멘 가게에 비유하면 이렇습니다.

프론트엔드홀 (손님이 보는 곳)손님에게 보여 줄 화면을 만든다이 예시: Next.js
→
백엔드주방 + 주문 창구데이터를 관리하고, 정해진 창구(API)로 내준다이 예시: Strapi
→
DB식재료 창고데이터를 오래 보관한다이 예시: PostgreSQL
홀 직원(프론트엔드)은 창고(DB)에 직접 들어가지 않습니다. 주방의 창구(API)에 "메뉴 목록 주세요"라고 주문하고, 받은 것을 손님 앞에 예쁘게 차립니다. 창구는 출입증(API 토큰)이 있는 직원의 주문만 받습니다.

WordPress에서는 이 셋이 한 덩어리였습니다. 이번에는 화면(Next.js)과 관리 도구·API(Strapi)를 나눠서, 둘이 어떻게 통신하는지 직접 만들어 봅니다.

왜 앱을 2개로 나누나요? 생략 가능
  • 역할 분리: 화면 디자인을 바꿔도 CMS는 그대로, CMS를 업데이트해도 화면은 그대로 둘 수 있습니다.
  • 보안: API 토큰을 Next.js 서버 안에만 두면, 브라우저에서는 절대 볼 수 없습니다.
  • 재사용: 같은 API를 스마트폰 앱이나 다른 사이트에서도 쓸 수 있습니다. 이런 구조를 헤드리스 CMS라고 합니다.

4. 내 PC의 개발 환경

개발은 내 PC에서 합니다. AWS와 같은 3층 구조를 PC 안에 작게 재현합니다.

5. 개발부터 배포까지

① 로컬에서 개발내 PC에서 만들고 확인01~04장
→
② PR"이 변경을 반영해 주세요"CI가 자동 검사 · 05장
→
③ 머지검사를 통과하면 main에 합침05장
→
④ 자동 배포main이 바뀌면 AWS에 반영CD · 06장

사람은 ①~③만 하면 됩니다. AWS 콘솔을 만지지 않아도 운영까지 반영됩니다(운영 데이터의 입력만 운영 관리자 화면에서 합니다. 07장에서 실제로 해 봅니다).

6. 코드로 하는 일, 관리자 화면으로 하는 일

Strapi를 쓰면 처음에 기본 설정만 코드로 해 두면, 그 뒤의 데이터 작업은 관리자 화면에서 끝납니다.

코드로 하는 일

· 저장소 뼈대, DB 컨테이너 (01장)
· 화면(Next.js) (04장)
· 자동 검사·배포 설정 (05·06장)
· 운영용 설정, AWS 구성 (06장)

Strapi 관리자 화면에서 하는 일

· 데이터 구조(스키마) 설계. 로컬에서만 (02장)
· 데이터 입력·수정·공개 (03장)
· API 토큰 발급 (03장)
· 사진 업로드

관리자 화면에서 만든 데이터 구조는 Strapi가 설계도 파일(schema.json)로 자동 저장하고, 이 파일은 코드처럼 Git으로 운영에 배포됩니다. 반면 입력한 데이터는 배포되지 않습니다. 운영에서는 운영 관리자 화면에서 입력합니다.

7. 사용하는 도구

프론트 Next.js

React 기반 웹 프레임워크. 서버에서 HTML을 만들 수 있어서, 토큰 같은 비밀을 서버에만 둘 수 있습니다.

백엔드 Strapi

오픈소스 헤드리스 CMS. 관리자 화면에서 데이터 구조를 만들면 API가 자동으로 생깁니다.

DB PostgreSQL

관계형 DB. 로컬에서는 Docker로, AWS에서는 Aurora로 실행합니다.

Docker

프로그램을 "컨테이너"라는 상자에 담아 어디서든 똑같이 실행합니다.

pnpm · Biome

패키지 관리(여러 앱을 저장소 하나에서) · 코드 모양 통일과 실수 검출.

CI/CD GitHub Actions · AWS CDK

자동 검사·자동 배포 · AWS 구성을 코드로 적는 도구.
